# Getting Started: working notes

Records of the Getting Started rebuild (PRDCT-487). Nothing here is published: the site builds
only from `src/content/docs/`. The authoring comments in the guide's pages point here for the
reasoning and evidence behind a sentence.

- `DECISIONS.md`: what was decided, by whom, and on what evidence, one dated entry each,
  append-only. Ends with an index of the open `VERIFY(owner)` flags.
- `CONSERVATION-REPORT.md`: every paragraph the rebuild moved or removed, and where it went, as
  the conservation rule in `CLAUDE.md` asks.
- `MISSING.md`: gaps the guide still has, with what closes each one.

Internal calls and chats are paraphrased here, never quoted word for word: the repo is public.
