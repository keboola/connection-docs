## Prepare a spreadsheet

You need a spreadsheet in Drive to load from. Open
[Google Sheets](https://www.google.com/sheets/about/), start a blank one, then use **File → Import**
to import [level.csv](/getting-started/level.csv) into it, and name the file `Level`. Twenty-eight
rows, two columns. Google's help covers [importing a CSV into Sheets](https://support.google.com/docs/answer/40608)
if the menu has moved since we wrote this.

Treat it as a table a colleague shared with you.

## Set it up

<Tabs syncKey="howto">
<TabItem label="Prompt">

Kai can create the configuration
([integration setup](/kai/use-cases/#integration-setup)) but not authorize it. Open **Kai Agent**
in the top bar:

```text title="Prompt" wrap
Create a Google Sheets data source configuration called "Level from Sheets".
```

Then do the authorization and the file picking yourself, steps 5 to 9 in the **UI** tab. Both
happen inside Google rather than Keboola: the consent screen, and the Drive picker where you
choose the *spreadsheet* you just made.

Once the spreadsheet is selected, hand it back:

```text title="Prompt" wrap
In "Level from Sheets", select the sheet inside that spreadsheet, run the configuration, and tell me what table it created and how many rows it has.
```

Watch the wording in both prompts. The *spreadsheet* is the file in Drive; the *sheet* is the tab
inside it. The connector asks for them in that order.

</TabItem>
<TabItem label="UI">

1. Go to **Components** and click **Add Component**.

   ![Screenshot - The Components page, with Components highlighted in the top navigation and a red arrow pointing at the green Add Component button on the right](/getting-started/load/source-intro-0.png)

2. Search for the **Google Sheets** data source and open it.

   ![Screenshot - The Google Sheets data source dialog with the green Connect To My Data button next to the blue Use With Demo Data button](/getting-started/load/source-intro.png)

3. Click **Connect To My Data**. **Use With Demo Data** next to it loads a dataset Keboola
   prepared, which most connectors offer and which is not what you want here.

4. Name the configuration `Level from Sheets`, describe it, and click **Create Configuration**.
   The **Prompt** tab uses the same name, so either path leaves you in the same place.

   ![Screenshot - The Google Sheets dialog with Name and Description filled in, above the Create Configuration button](/getting-started/load/google-sheets-create.png)

   Every component can hold several [configurations](/components/), which is how one project
   extracts from two different Google accounts.

5. Click **Sign in with Google** to authorize the connector.

   ![Screenshot - The new Google Sheets configuration page with a red arrow on the Sign in with Google button in the Authorization section, above the Select sheets from Google Drive and Load data sections](/getting-started/load/sign-in-with-google.png)

6. Google takes over: it asks which account to use and what Keboola may reach in it. Pick the
   account holding the spreadsheet you just made and grant the access it asks for. Google's wording
   and buttons change from time to time, so follow the screen rather than a script from us.

7. Now choose the Drive files to import.

   ![Screenshot - The Select sheets from Google Drive section with a red arrow on the green Load Spreadsheet Documents from Google Drive button, above an empty area that reads Load data above to see sheets](/getting-started/load/select-files.png)

8. Google asks a second time. Step 6 let Keboola reach the account at all; this prompt is
   narrower, about which files it may see. Allow it for your spreadsheets and continue, because
   under-granting here leaves the picker in the next step empty.

9. Google's file picker opens. Find the `Level` spreadsheet and choose it.

10. Keboola reads the sheets inside that spreadsheet and offers them.

11. Select the sheet and click **Save and Run Configuration**.

    ![Screenshot - The Select sheets from Google Drive section with Level / level picked and an arrow on Save and Run Configuration, and Load data showing Last job status Success and an arrow on the Level-level table](/getting-started/load/save-and-run.png)

12. The connector creates its own output bucket and table. Click the table name to see what
    arrived, or go to **Storage**.

    ![Screenshot - The Storage page with the Google Sheets data source's IN bucket expanded and red arrows on it and its table Level-level, both just updated by that configuration](/getting-started/load/storage.png)

The new table holds 28 rows, the ones you uploaded into the spreadsheet, with the column names
from its first row.

## If it goes wrong

- **The job fails on permissions.** The authorization was revoked or expired in the Google
  account. Re-authorize the configuration; the file selection survives.
- **The spreadsheet is not in the picker.** It belongs to a different Google account from the one
  you authorized. Authorize that account, or share the file with this one.
- **The table arrives with one row of data and a header called `1`, `2`, `3`.** The sheet's first
  row was not treated as a header. Check the sheet settings in the configuration.
- **Nothing happens after selecting the sheet.** Selecting saves the configuration; loading is a
  separate run. Click **Run Component**.
