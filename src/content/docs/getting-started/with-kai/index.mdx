## How it goes

- **Where:** paste each prompt into **Kai Agent**, except the app's, which goes into the Apps
  builder (**Apps** in the navigation, then **Create app** if the project already has an app).
  A step's prompts go in the same chat; in our 8 October run all the Kai Agent prompts went into one.
- **When to paste the next:** once the step is done. Each step below says how to tell, and its
  page has the full **Check**.
- **What Kai asks:** approve each change it proposes, 15 approvals in both our runs without the app's
  optional publish; a question that only reads asks for none by default. To be asked less, click
  **Always allow** on a card, or set the tools in the Kai panel's settings (the gear, then
  **Tools**, see [tool permissions](/kai/settings/#tool-permissions)): a tool set to **Always
  allow** runs without asking. An approval left
  unanswered for about five minutes counts as declined: Kai says so, and you ask it to try again.
  [Approvals and plan mode](/getting-started/#approvals-and-plan-mode) says what asks, what does
  not, and how to undo a step.
- **If Kai asks you something:** answer it. If the forecast has cold, dry days (under 18 °C, no
  rain) that the sample's one summer of sales never had, Kai may stop at the transform step to ask
  what to do with them; **Leave them blank** keeps to the guide, which reads an empty cell as "no
  history" (the transform page's **Check**).
- **If a step comes out different:** its page's **Check** and the folds under it say what to do. If
  staffing_outlook landed in another bucket, put its table ID in the app prompt.

<details>
<summary>Why not one prompt for everything</summary>

Asked for loading, the forecast and the join in one prompt, Kai built the first part and stopped,
answering *"I'll tackle this in stages"* and waiting for *continue*, in both runs (3 and 8
September). One prompt would not save approvals either, since Kai asks before each change. In the
8 September run, four separate prompts in one chat ran to the end without a nudge, in 14 minutes
with 12 approvals, which is why this page gives the prompts one by one.

</details>

## What you have now

A pipeline that loads the data, joins it, answers the question in an app and rebuilds itself every
Monday. To see all of it in one answer, ask Kai:

```text title="Follow-up prompt" wrap
List everything the Getting Started guide created in this project (the Boolabean configurations, tables, the app and the flow) and what each does.
```

It only reads, so it asks for no approval by default.
[Check Storage and Jobs](/getting-started/check/#what-you-should-have) lists what should be there.
