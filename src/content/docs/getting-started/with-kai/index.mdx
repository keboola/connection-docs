The guide builds one pipeline for six cafés, to answer one question: **Which day next week will
leave a café short-handed?** This page has every prompt for it in one place. Kai builds each step
from a prompt you paste, and you approve what it asks; the step pages cover the same steps with the
click-through and terminal ways, and explain what each one does.

## How it goes

- **Where:** paste each prompt into **Kai Agent**, except the app's, which goes into the Apps
  builder (**Apps** in the navigation, then **Create app** if the project already has an app).
  A step's prompts go in the same chat; in our 8 October run all the Kai Agent prompts went into one.

- **When to paste the next:** once the step is done. Each step below says how to tell, and its
  page has the full **Check**.
- **What Kai asks:** approve each change it proposes; each step below says how many to expect. To
  be asked less, set the tools to **Always allow**:
  [Approvals and plan mode](/getting-started/#approvals-and-plan-mode) says how, what does not ask,
  what happens to an approval nobody answers, and how to undo a step.
- **If Kai asks you something:** answer it. In a week with cold, dry days Kai may ask at the transform
  step; that step's card says what to pick.
- **If a step comes out different:** its page's **Check** and the folds under it say what to do. If
  staffing_outlook landed in another bucket, put its full table ID (ask Kai for it) in the app prompt.

<details>
<summary>Why not one prompt for everything</summary>

Asked for loading, the forecast and the join in one prompt, Kai built the first part and stopped,
answering *"I'll tackle this in stages"* and waiting for *continue*, in both runs (3 and 8
September). One prompt would not save approvals either, since Kai asks before each change. In the
8 September run, four separate prompts in one chat ran to the end without a nudge, in 14 minutes
with 12 approvals, which is why this page gives the prompts one by one.

</details>

## What you have now

A pipeline that loads the data, joins it, answers the question in an app and rebuilds itself every
Monday. [Check Storage and Jobs](/getting-started/check/#what-you-should-have) lists what should be
there, with a prompt that has Kai list all of it in one answer.

## What is left to you

- **Notifications:** nobody hears about a failed run until you add a recipient in the flow's
  [notifications](/getting-started/automate/#set-up-notifications).
- **Sharing the app:** nothing is published until you say so; [publishing it](/getting-started/app/)
  gives others a link to the app, behind a password.
