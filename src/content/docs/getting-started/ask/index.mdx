## Reading is different from building

Everywhere else in this guide Kai stood in for your clicking. Here it reads what you built.
Querying a table and calculating a metric is
[Data Exploration](/kai/use-cases/#data-exploration), and it needs nothing set up. Nothing on
this page changes the project either: reading is what Kai's read-only tools do, and those are
allowed without asking by default — so expect an answer rather than an approval dialog, unless
this project's [tool permissions](/kai/settings/#tool-permissions) have been set to ask.

## Ask it

:::tip[The question the guide started with]
```text
Using out.c-octopus-atlas.octopus_atlas, answer this: which ocean basin has the most recorded
octopus sightings, what share of all 10,000 sightings does it carry, and how many distinct
species were recorded there?
```

**Check:** the **North Atlantic**, with **2,632** sightings — about **26%** of the table — from
**50** distinct species.
:::

An answer is a place to start, not to stop:

```text
And how deep do they really go — what is the deepest sighting in the table, which species was
it, and which depth zone does that fall in?
```

**Check:** **4,838 meters**, *Grimpoteuthis challengeri*, squarely in the **abyssal zone**. That
is the kind of thing nobody sees in four separate files, and it took one question because the
pipeline had already put the zone next to the depth.

**If the numbers come out different**, Kai wrote its own SQL and may have drawn the lines
somewhere else — counted regions from raw coordinates, or treated empty depths as zeros. The
definitions this guide uses are the columns your transformation already wrote; point Kai at those
rather than re-prompting blind.

## The same request, as one prompt

You built this one step at a time so every result stayed checkable. Once you have seen the
pieces, the loading and the joining are one request rather than two:

```text
Load the four CSVs from https://help.keboola.com/getting-started/ — occurrences.csv,
species.csv, depth_zones.csv and basins.csv — into Storage. Then join them into one table with
display names, depth zones and ocean basins, and tell me which ocean basin has the most
sightings.
```

Kai still asks you to approve what it creates. Swap the file URLs for your own data and the same
sentence builds *your* pipeline instead.

The part of the question still open is *"how close to **your** coast?"* — a number is a poor
answer to that. The next page turns the table into a map anyone can open.
