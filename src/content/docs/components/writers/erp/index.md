Data destination connectors export data from Keboola to external systems. The ERP connectors write into STORMWARE's accounting products: mPOHODA, the cloud edition, through its REST API, and the desktop POHODA, through a POHODA mServer running on your own server. Each has a matching [data source connector](/components/extractors/erp/) for reading the same agendas back.

<!-- Explanation-type page. Category index, modelled on components/writers/other, 2026-10-12. -->

Keboola provides the following ERP data destination connectors:

- [mPOHODA](/components/writers/erp/mpohoda/) creates invoices, orders, offers, business partners and other records in the mPOHODA cloud accounting service.
- [POHODA mServer](/components/writers/erp/pohoda-mserver/) imports address book entries, invoices, orders, stock and other agendas into STORMWARE POHODA through mServer.
